# TypeScript Ödev 3 – BGP 201

Bu repo, **TypeScript Ödev 3** kapsamında hazırladığım 20 sorunun tamamını içeriyor.  
Her soru ayrı `.ts` dosyasında yer alıyor ve hem derlenebilir hem de çalıştırılabilir durumda.

## İçerik
- **Soru1.ts:** Jenerik dizi birleştirme (`mergeArrays`)
- **Soru2.ts:** Type Guard kullanımı (`useVehicle`)
- **Soru3.ts:** Private özellikli `Logger` sınıfı
- **Soru4.ts:** `keyof` ile jenerik `getProperty` fonksiyonu
- **Soru5.ts:** Fonksiyon overload örneği (`search`)
- **Soru6.ts:** `MemoryCache` sınıfı (set/get/clear)
- **Soru7.ts:** `updateUser` fonksiyonu (`Partial` + `Readonly`)
- **Soru8.ts:** Rest parametreleri ile toplama (`sum`)
- **Soru9.ts:** Soyut sınıf ve `Circle` örneği
- **Soru10.ts:** Statik özellik ve metod (`MathHelper`)
- **Soru11.ts:** `UnwrapPromise<T>` tipi
- **Soru12.ts:** `GetReturnType<T>` tipi
- **Soru13.ts:** `CreateGetters<T>` mapped type
- **Soru14.ts:** `DeepReadonly<T>` tipi (derin readonly)
- **Soru15.ts:** `PickByValueType<T, V>` mapped type
- **Soru16.ts:** `UserID` ve `PostID` branded tipleri
- **Soru17.ts:** `FilterUnion<T, U>` conditional type
- **Soru18.ts:** `LastParameter<T>` tipi
- **Soru19.ts:** `Flatten<T>` tipi
- **Soru20.ts:** `ParseRouteParams<T>` tipi (template literal parsing)
